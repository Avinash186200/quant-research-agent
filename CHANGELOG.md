# Changelog

All notable changes to this repository are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.2.0] - 2026-11-15

### Changed
- Docs: training-grade README and walkthrough. The README now has a plain-English problem statement, a pipeline
  diagram with steps, key concepts, "What you will learn", a clearer synthetic label and a complete layout.

### Added
- `docs/methodology.md`: the strategy contract, what each check does and when it flags, PSR / DSR, the two
  auditors and how the eval is scored, all matching the code.
- `docs/walkthrough.md`: the deterministic auditor on three strategies, with numbers from a real run.

## [1.1.0] - 2026-11-15

### Added
- `CHANGELOG.md`, `CONTRIBUTING.md` and a documentation index in `docs/README.md`.

## [1.0.0] - 2026-11-04

### Added
- First public release: the maintained code, documentation, tests and CI.
